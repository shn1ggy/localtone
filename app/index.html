Search guide

Fields

artist: albumartist: album: title: genre: year: rating: track: disc: / discnumber: has: duration: (seconds) format: / codec: folder:

Operators

Quote phrases. AND combines terms; OR accepts either; NOT or EXCEPT excludes the next term or parenthesized group.

Tags present

has:field finds tracks with a nonempty value. Supported fields: title, artist, albumartist, album, genre, year, rating, track, disc (or discnumber), totaltracks, duration, format (or codec) and folder.

has:disc checks the actual disc-number tag, not the Disc 1 fallback. has:rating means a rating above zero; numeric tags require a positive value. NOT has:genre is equivalent to missing:genre. Generated artist/title labels do not count as tags.

Combine presence checks with AND, OR and NOT. The same syntax works in dynamic playlists using Search expression. Album views show albums containing matching tracks.

Missing tags

Use missing:year, missing:artist, missing:albumartist, missing:album, missing:title, missing:genre, missing:rating or another supported field. Missing artist/title tags are detected even when a folder or filename is displayed instead.

missing:leadingzeros finds unpadded single-digit numbers in the raw track-number or total tag (such as 7/9). missing:totaltracks finds absent or invalid totals. Display formatting does not affect these checks. The same syntax works in dynamic playlists using Search expression.

has:disc (or has:discnumber) finds tracks with a disc-number tag. missing:disc finds tracks without it; disc:2 finds tagged Disc 2. has:year, has:genre and other supported fields work too. Album views show albums containing matching tracks.

Examples

has:genre AND missing:year
has:artist AND has:albumartist
has:totaltracks AND NOT has:rating
has:disc
disc:2 AND has:genre
missing:leadingzeros OR missing:totaltracks
missing:genre AND NOT missing:artist
artist:"Nine Inch Nails" year:1990-1999
EXCEPT genre:"hip hop"
rating:>=4 AND (genre:ambient OR genre:electronic)
