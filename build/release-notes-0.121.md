Localtone 0.121.0 improves the first-launch experience.

- A fresh collection shows Add library… and Import settings… directly in the main pane, with compact 28px buttons and the existing theme. No setup wizard opens automatically.
- First-launch import reuses the existing settings-backup validation, confirmation and backup workflow. Importing a backup applies its saved browsing tab and default sort order; existing installations retain their current browsing flow.
- Pending imports prevent duplicate requests. Cancellation leaves the screen ready to use, and invalid backups show a concise inline error.
- Tab navigation reaches Add library, then Import settings; Enter/Space activate the buttons. Shift+Tab retains sidebar navigation.
- Empty playlists, unsuccessful searches and indexed-but-empty folders retain their own concise guidance. Existing music collections and preferences stay intact.

From 0.118 or newer, use Settings → About → Check for updates, download/extract, then Prepare update… to copy portable data when moving to a new folder. Downloading does not install or restart automatically. Quit before replacing an app in place and preserve Localtone-data.

Mac downloads are ad-hoc signed and verified in native CI, not Developer ID signed or notarized. Windows/Linux packages, application and decoder sources, and SHA-256 checksums are included.
