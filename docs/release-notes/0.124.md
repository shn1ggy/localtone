# Localtone 0.124.0

- Double-click a library or All music to start a random track, matching playlist playback. The queue includes the complete collection and preserves shuffle/repeat behavior.
- Shuffled-next now positions the current album heading and cover at the top, matching the now-playing artwork click while keeping the active tab. Sequential Next/Previous retain nearest-edge scrolling.

Early access. Unsigned test packages for macOS (Apple Silicon and Intel), Windows and Linux. macOS packages use ad-hoc signing and are not notarized.
