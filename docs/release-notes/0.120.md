Localtone 0.120.0 improves selection, playback navigation and track-number display.

- Clicking empty space in the track pane clears track and album selection without moving the scroll position.
- Next/previous track navigation preserves expanded albums and the current collection scroll position. Tracks already in view stay in place; off-screen tracks use nearest-edge scrolling rather than vertical centering.
- Appearance → Albums & tracks now includes Show disc number. It prefixes the displayed track number with the disc number and a dot, preserving metadata padding (for example, 02.07/19). The setting is saved, off by default, and number-column space adjusts to fit. Untagged discs display as disc 1.
- Finder/Explorer files imported into regular playlists remain in those playlists but are excluded from All music, as well as dynamic playlists.

From 0.118 or newer, use Settings → About → Check for updates, download/extract, then Prepare update… to copy portable data when moving to a new folder. Downloading does not install or restart automatically. Versions 0.116–0.117 need one manual download because their updater can cancel redirects. Quit before replacing an app in place and preserve Localtone-data.

Mac downloads are ad-hoc signed and verified in native CI, not Developer ID signed or notarized. Windows/Linux packages, application and decoder sources, and SHA-256 checksums are included.
