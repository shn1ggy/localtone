# Localtone 0.125.0

- Double-click random playback now reveals and selects the playing track in the current tab, with its album heading and cover at the top where applicable.
- Right-click Albums, Covers or Tracks to toggle column headings. Shift+X changes the same saved setting.
- Queue context actions now follow Add to play queue → Add to playlist → Create playlist from selection.
- Shift+Backspace confirms removing a library/playlist, or selected tracks/albums from a regular playlist, without deleting music files.
- A separate Delete files permanently… media context action confirms irreversible disk deletion, updates all collection references, and removes empty album/artist folders while preserving library roots and nonempty folders.

Early access. macOS packages are ad-hoc signed and not notarized. Permanent file deletion cannot be undone; playlist removal retains session undo.
